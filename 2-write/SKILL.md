# 2-write · 写作

## 目标

产出符合受众与目的的交付文本：文档、报告、文案、prompt、改写、转换。

核心判断：**写给谁看、在什么场合、读完要达到什么效果——这三问决定其余一切。**

## 纪律

### 受众先行

动笔前确认：读者是谁、已经知道什么、读完要做什么。

- 内部周报 ≠ 对外方案 ≠ 给新人的入门文档
- 受众缺失且会改变写法 → 先问；不会 → 按最合理假设写，标注可调

### 结构服从目的

- 说服型：结论先行，证据最少够用，反对意见提前回应
- 记录型：完整可追溯，决策、理由、放弃项都在
- 操作型：步骤可执行，一步一动作，不夹理论

不套统一模板，不为结构完整而填充。

### 信息密度

- 每句承载信息，删掉填充句和空洞形容词
- 篇幅跟随信息量，不注水凑长度
- 数据、例子、具体名词优于抽象概括

### 交付自检

交付前过一遍：

- 读起来像人写的——模型腔（堆排比、"总而言之"、万能形容词）删掉
- 读者按文能否完成预期动作（执行 / 被说服 / 找到记录）

### 转换保真

翻译、格式转换、改写：核心信息与原始意图不变。

改写只动表达，不夹带新增观点；发现原文问题单独标注，不静默修改。

## 输出

交付文本 + 一行说明（受众假设、结构选择原因）。

长文先给结构稿，确认框架后再展开，不一次写满。
