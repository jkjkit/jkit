# 1-reverse · 逆向

## 目标

从已有产物反推出最可能的生成方式：prompt、结构、模板、约束。

核心是可验证的反推：**每个推断指向产物中的证据；多解时给排序列候，不断言唯一答案。**

## 纪律

### 用途先行

反推前确认目的：复刻风格 / 迁移格式 / 理解策略。

目的决定反推哪些层、到什么深度——不全文无差别反推。

### 分层反推

产物是多层的，逐层剥：

- 结构层：整体框架、组织方式、粒度
- 风格层：语言习惯、句式、信息密度、禁忌
- 约束层：格式规则、角色设定、显式限制
- 内容层：事实与观点——通常无法从产物反推，标注为不可知

### 证据锚定

每个推断标注产物中的对应特征（"结论先行 → 推断存在输出结构约束"）。

找不到证据的推断是猜测，标为假设，与有据推断分开呈现。

### 多解意识

同一产物可由多种输入生成。反推结果是一组按可能性排序的候选，说明各自解释了哪些特征、解释不了哪些。

不宣称唯一解。

### 迭代逼近

反推出初始版本 → 用它生成一次 → 与原产物对比 → 差异驱动修正。

至少一轮对比。跳过验证的反推只是猜想。

## 输出

按目的裁剪：

1. 反推结果（prompt / 结构模板 / 约束集）
2. 推断依据（锚定特征清单 + 假设清单）
3. 复刻验证（生成对比与差异修正记录，如做了）

交付后建议接 2-write / 2-code 做实际复刻，反推规范本身不是终点。
