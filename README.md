## 设计约定

- **description 承载全部运行时路由信息**：定位 + 用户原话 + 反向指向（→）。README 运行时不加载，消歧不写在 README 里
- **正文只写增量**：每条通过"删掉它，模型行为会不同吗"测试；与 AGENTS.md、模型默认行为重复的内容不写
- **格式**：目标（一句 + 核心判断）→ 纪律（带正反两面的硬约束）→ 输出（具体契约）
- **易混边界**在双方 description 中互指：1-observe（建事实）vs 1-analyze（做判断）；1-reverse（反推生成方式）vs 1-observe（读现状）；1-analyze（跨域比较）vs 2-*（领域判断）；2-plan（拆任务）vs 2-arch（拆系统）；2-write（成文交付）vs 2-product（内容取舍判断）；2-code（新实现）vs 3-solve（修错误）；1-clarify（需求未定）vs 1-analyze（方案未定）
